# 03 NPC System

## 目标 / 范围（What & Why）
- 定义 NPC 的分层行为架构、职业岗位与需求状态体系。
- 支撑“活体移动基地”的持续运作与玩家协作体验。

## 术语表
- 顶层选择行为树：在全局目标间做切换的决策层（TBD）。
- 中层行为树：实现某类行为簇（工作/休息/进食等）的流程层（TBD）。
- 底层任务动作：可执行原子动作（移动、交互、生产等）（TBD）。

## 系统边界
- 管：NPC 决策框架、职业分工、需求与效率惩罚规则。
- 不管：具体动画蓝图细节、语音演出、剧情演出脚本。

## 核心流程（伪流程）
1. 评估 NPC 当前需求与岗位优先级。
2. 顶层选择行为树决定目标行为簇。
3. 中层行为树拆解任务步骤。
4. 底层动作执行并反馈结果。
5. 更新状态（效率/满意度/疲劳等）并循环。
