# 04 Building System

## 目标 / 范围（What & Why）
- 定义城堡基地建造规则、分类与解锁策略。
- 保证建造系统与移动城堡逻辑兼容，避免结构失效。

## 术语表
- 建筑件：可放置的结构单位（地基/墙/天花板/斜坡等）。
- 配方解锁：通过章节、任务或科技开启建造能力（TBD）。
- 结构规则：限制建筑放置位置与合法性的约束集合（TBD）。

## 系统边界
- 管：建筑分类、配方管理、特殊放置规则。
- 不管：材质美术规范、高模制作流程。

## 核心流程（伪流程）
1. 检查当前解锁与资源条件。
2. 选择建筑件并校验放置合法性。
3. 扣除资源并生成结构。
4. 更新结构稳定/移动兼容状态（TBD）。
5. 同步到存档与 NPC 可用工作环境。
