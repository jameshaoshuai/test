# 01 Gameplay Loops（主循环与节奏）

## 目标 / 范围（What & Why）
- 定义玩家在“生存—采集—建造—战斗—推进”之间的循环节奏。
- 为章节内容提供可落地的玩法骨架。
- 不包含具体平衡数值与掉率（TBD）。

## 术语表
- 生存压力：由温暖/饥饿/睡眠/受伤等形成的持续约束（TBD）。
- 资源门槛：解锁某阶段建造或任务所需的最低资源条件（TBD）。
- 风险回报比：行动收益与受伤/消耗风险之间的关系（TBD）。

## 系统边界
- 管：循环阶段定义、关键资源分类、前中期节奏建议。
- 不管：具体 UI 交互细节、AI 路径、底层存档字段。

## 核心流程（伪流程）
1. 检查生存状态（温暖/饥饿/睡眠/受伤）。
2. 决定当日目标（补给/扩建/任务推进）。
3. 外出采集与风险对抗。
4. 回城处理生产与建造。
5. 恢复状态并触发下一阶段目标。
