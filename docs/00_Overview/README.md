# 00 Overview

## 目标 / 范围（What & Why）
- 说明《Moving Castle》的核心定位：移动城堡上的生存与建造体验。
- 统一项目语言，减少设计、程序、关卡、叙事之间沟通偏差。
- 本文档覆盖产品层与章节层的概念，不覆盖具体数值平衡（TBD）。

## 项目电梯陈述
- 玩家在一座可移动、可升级的城堡基地上探索、采集、建造与生存。
- NPC 具备职业分工与日常行为，辅助玩家维持城堡运转。
- 游戏按章节推进，逐步开放移动能力与世界复杂度。

## 核心卖点（USP）
- 移动城堡作为“动态基地”的核心体验。
- 生存建造与章节化探索节奏结合。
- NPC 职业系统与行为树带来的“活体基地”感。
- Chapter 2 的碎裂空岛 + 码头跳转结构（EA 主体）。

## 玩家体验主循环（高层）
1. 规划当前目标（生存/扩建/推进章节）。
2. 离开城堡探索并收集资源。
3. 返回城堡生产、建造、分配 NPC 工作。
4. 处理风险事件（怪物、受伤、补给缺口）。
5. 完成阶段目标并解锁下一能力/区域。
6. 重复循环，进入更高复杂度区域。

## 章节路线概览（Chapter 1/2/3）
- Chapter 1：线性路线推进；城堡自动沿路线移动；玩家不可控制方向。
- Chapter 2：碎裂空中岛屿；引入城堡飞行能力；岛内自由移动；通过固定码头线性跳转。
- Chapter 3：连续大陆规划；系统耦合与世界复杂度显著提升（TBD）。
