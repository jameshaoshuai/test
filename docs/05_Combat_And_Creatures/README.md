# 05 Combat And Creatures

## 目标 / 范围（What & Why）
- 建立基础战斗体验与敌对生物生态。
- 让战斗与资源门槛、建造推进形成闭环。

## 术语表
- 攻击型生物：主动接敌并压迫玩家的敌人类型（TBD）。
- 防守型/区域型生物：守卫资源点或关键路径的敌人类型（TBD）。
- 资源门槛掉落：用于合成/升级的关键战利品（TBD）。

## 系统边界
- 管：敌人类型框架、战斗手段占位、掉落与门槛规划。
- 不管：具体动作帧数据、特效制作细节。

## 核心流程（伪流程）
1. 玩家进入风险区域并遭遇生物。
2. 选择战斗或规避策略。
3. 结算伤害与状态变化。
4. 掉落资源并回流到建造/制作。
5. 根据章节解锁更高层战斗挑战。
