# 02_02 Chapter2（碎裂空岛 + 飞行 + 码头跳转）

## 目标 / 范围（What & Why）
- 作为 EA 主体内容，建立“空中岛屿群探索 + 城堡飞行”的核心乐趣。
- 在岛屿内提供更高自由度移动；岛屿间通过固定码头线性跳转。

## 术语表
- 碎裂空岛：相互分离、结构多样的空中地块集合（TBD）。
- 码头节点：城堡可停靠并触发跨岛迁移的固定点位（TBD）。
- 飞行状态：城堡可在特定规则下移动的状态集合（TBD）。

## 系统边界
- 管：跨岛结构、飞行能力引入、EA 主体推进框架。
- 不管：Chapter 3 连续大陆无缝探索细节。

## 核心流程（伪流程）
1. 解锁飞行基础能力。
2. 在当前岛屿内自由探索与资源循环。
3. 达成码头跳转条件。
4. 执行线性跳转至下一目标岛屿。
5. 完成阶段目标并逐步扩展可达区域。
